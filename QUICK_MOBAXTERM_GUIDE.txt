## 下载视频方法

### 方法A: MobaXterm SFTP (推荐)
1. 在MobaXterm中按 `Ctrl+S` 打开SFTP
2. 导航到 `/root/.local/share/isaacgym/` 或脚本输出的路径
3. 找到 `.mp4` 文件
4. 拖放到本地Windows文件夹

### 方法B: scp命令 (在Windows CMD/PowerShell中)
```bash
scp -P 11092 root@ry3.9gpu.com:/root/.local/share/isaacgym/*.mp4 .
```

### 方法C: MobaXterm Session中用scp
```bash
scp -P 11092 root@ry3.9gpu.com:/root/.local/share/isaacgym/*.mp4 /path/to/windows/folder
```

## 常见问题

**Q: 脚本找不到模型?**
```bash
# 检查模型存在
find /root/RoboDuet/runs -name "ac_weights_*.pt" -type f | head -3
```

**Q: 生成速度很慢?**
```bash
# 这是正常的 - IsaacGym rendering很耗时
# 600步 = 约10秒视频 = 5-10分钟生成时间
```

**Q: 如何生成更短的视频?**
编辑 `gen_video_v2.py` 第101行:
```python
for step in range(600):  # 改为 range(300) = 5秒
```
